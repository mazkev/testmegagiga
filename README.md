A high-fidelity, professional inventory management system designed for modern businesses. Built with Vue.js and Tailwind CSS, featuring a sleek OLED-friendly dark mode, real-time analytics, and comprehensive reporting.

---

## ✨ Key Features

### 📊 Professional Analytics
- **Stock Distribution**: Visualize inventory balance across all suppliers with interactive Donut charts.
- **Top 5 Highlights**: Instant visibility into your highest-stock items via horizontal bar charts.
- **Real-time Updates**: Visualizations react instantly to inventory changes.

### 🌓 Obsidian Dark Mode
- **Seamless Transition**: Fully theme-aware UI that toggles between a clean Light Mode and a premium OLED Dark Mode.
- **High Contrast**: Optimized for readability and reduced eye strain during long working hours.

### 📄 Data Portability & Reporting
- **PDF Export**: Generate professional inventory reports with one click, ready for auditing.
- **Excel Export**: Download your entire database as a spreadsheet for advanced processing.
- **Audit Logs**: Track every action (Login, Create, Update, Delete) with a detailed system activity history.

### 🛡️ Robust Management
- **Inventory Control**: Full CRUD operations for items with price, stock, and supplier tracking.
- **Supplier Directory**: Manage your mitra bisnis with a dedicated supplier database.
- **Local-First Persistence**: Data is securely stored in LocalStorage for lightning-fast, offline-capable performance.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v14 or higher)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

### Installation
1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/marketplace-invent.git
   cd marketplace-invent
   ```

2. **Install dependencies**
   ```bash
   npm install
   # or
   yarn install
   ```

3. **Start development server**
   ```bash
   npm run serve
   # or
   yarn serve
   ```

4. **Build for production**
   ```bash
   npm run build
   # or
   yarn build
   ```
